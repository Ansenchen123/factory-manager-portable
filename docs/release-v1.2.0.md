# v1.2.0 前台維護工作台 · Windows 可攜版

開啟程式選擇存檔後，預設進入維護工作台。原本的產線、機台與耗材管理功能集中到右上角「後台管理」，不需密碼，可隨時返回前台。

![維護工作台](https://raw.githubusercontent.com/Ansenchen123/factory-manager-portable/v1.2.0/docs/screenshots/front-desk.png)

- 「已逾期」與「今天需要維護」分開顯示，每筆均標明產線、機台及耗材名稱。
- 勾選即記錄今天完成並自動儲存，依維護週期更新下次日期；完成後從待辦清單移除。
- 每筆完成操作有 15 秒可復原；切換存檔或進入後台時會清除暫時的復原操作。
- 搜尋全部耗材，支援產線、機台名稱／編號、耗材名稱與料號，也能提前完成尚未到期的項目。
- 搜尋結果會將今日已完成項目顯示為已勾選，避免重複操作；存檔失敗時保留待辦並提供錯誤提示。
- 後台保留新增、編輯、刪除、複製貼上、排序及跨產線拖曳功能，切回前台時保護未儲存的草稿。

## 下載與升級

- `Factory.Manager.Portable.1.2.0.exe`：Windows x64 單檔可攜版。
- `Factory.Manager.Portable-1.2.0-win.zip`：Windows x64 資料夾版，解壓縮後執行程式。
- 可直接開啟 v1.1.1 的 JSON 存檔，資料格式未變。升級時保留原有 `data` 資料夾；單檔版預設存檔仍位於 EXE 旁的 `data/factory-data.json`。

## 驗證

53 項自動測試、TypeScript 檢查與正式建置通過。Windows 打包程式實測前台搜尋、勾選、復原、存檔重開、後台切換、原生剪貼簿、拖曳排序與 320–1440px 排版；測試資料統一存放在 `test-data/runtime/`。
