# v1.1.1 Windows 可攜版

產線與機台可拖動排序，機台也可拖到其他產線，並保留耗材與維護紀錄。拖動結果會自動儲存。

- 修正拖曳影像太透明：改用程式繪製的預覽卡片，滑鼠旁的影像實際採用 80% 不透明度，不再疊加瀏覽器原生拖曳影像的透明效果。
- 修正編輯按鈕列空白區無法選取；編輯時同步選取對應產線或機台。
- 放下或按 Escape 取消拖動後會移除預覽；無效落點與儲存失敗不改動現有資料。
- 包含維護日期編輯、預定維護日期、複製貼上與上下排序等 v1.1 改善。
- 可攜版預設資料存放在原始 EXE 旁的 data 資料夾。

下載：`Factory Manager Portable 1.1.1.exe` 為單檔可攜版；`Factory Manager Portable-1.1.1-win.zip` 為資料夾版。

驗證：43 項自動測試、TypeScript 檢查、正式建置通過；已在 Windows 打包程式實測拖放、80% 預覽、Escape 取消、跨產線移動、存檔重開、原生剪貼簿與 320–1440px 排版。
