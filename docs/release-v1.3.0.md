# v1.3.0 可攜版自動更新 · Windows

啟動時自動檢查 GitHub 正式版本，顯示新版與更新內容。按「下載並更新」後，自動下載、驗證檔案、關閉程式並重啟新版。

- 保留免安裝單檔 EXE 的使用方式，更新沿用原本檔名與位置。
- SHA-256 驗證成功後才套用更新；下載失敗或檔案損壞可直接重試。
- 尚有未儲存內容或存檔作業時，先完成儲存或取消編輯，再重新啟動更新。
- 工廠 JSON 存檔保留原位，重啟後進入選檔畫面。
- 更新工具等待舊程式退出後替換 EXE；啟動新版失敗時還原並啟動原有 EXE。
- 版本按鈕提供「檢查更新」，支援手動重新檢查。
- ZIP／資料夾版提供官方下載頁入口；自動替換適用於 Windows x64 單檔可攜版。

## 下載與升級

- `Factory.Manager.Portable.1.3.0.exe`：Windows x64 單檔可攜版，支援自動更新。
- `Factory.Manager.Portable-1.3.0-win.zip`：Windows x64 資料夾版。
- v1.2.2 及更早版本：先下載並換上 v1.3.0 EXE 一次，保留原有 `data` 資料夾，之後即可由程式檢查並套用新版。
- v1.3.0-test.1 單檔可攜版：可直接透過程式內的「檢查更新」升級至本正式版。
- 更新下載與原有 EXE 保存於程式旁的 `.factory-update-*` 資料夾；確認新版正常後可刪除該更新資料夾。
