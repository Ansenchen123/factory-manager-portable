# v1.3.3 輸入焦點與選取修正 · Windows

## 修正

- 升級至 Electron 43.7.11，修正 Windows 原生確認框關閉後無法輸入、必須切換視窗才恢復的問題。
- 刪除選中的產線或機台後，正式更新到有效的選取項目，避免後續排序造成選取跳動。
- 在空清單首次貼上產線或機台後，寫回選取 ID，後續排序保持正確父層。

## 驗證與文件

- 84 項自動測試、正式封裝版的桌面／前台／版面／拖曳／更新／生命週期 smoke，以及 Windows 更新替換助手測試通過。
- 新增狀態機、逐項原生驗收程序及失敗／重試路徑測試。
- Windows 原生操作已驗證刪除後立即輸入及建立機台、微軟注音鍵盤組字、原生還原對話框與關閉取消後的輸入。
- 驗收紀錄區分自動測試、原生操作與尚未完成分支；本版依使用者確認發布。
