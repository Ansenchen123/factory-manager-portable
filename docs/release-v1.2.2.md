# v1.2.2 後台緊湊版面與全新圖標 · Windows 可攜版

後台減少留白，空白存檔在預設視窗即可完整操作，並套用全新的工廠維護圖標。

- 移除後台面板固定高度與底部多餘空白，將資料摘要整合至頂部。
- 機台表單在選擇產線後顯示，耗材表單在選擇機台後顯示，操作順序更清楚。
- 壓縮表單間距、整合耗材欄位與操作按鈕；在 1280×720 可完整顯示一條產線、一台機台與一筆耗材。
- 空白後台在預設視窗、1280×720、1366×768 與 1024×768 均不需滾動。
- 全新深綠工廠剪影與維護勾號圖標，套用於 Windows EXE 與程式視窗，ICO 包含 16–256px 共九種尺寸。
- 保留前台搜尋、逾期／今日待辦、勾選完成、15 秒復原，以及後台複製貼上、排序與跨產線拖曳。

## 下載與升級

- `Factory.Manager.Portable.1.2.2.exe`：Windows x64 單檔可攜版。
- `Factory.Manager.Portable-1.2.2-win.zip`：Windows x64 資料夾版，解壓縮後執行。
- 可直接開啟既有 JSON 存檔。升級時保留原有 `data` 資料夾；單檔版預設存檔仍位於 EXE 旁的 `data/factory-data.json`。

53 項自動測試、TypeScript 檢查與正式建置通過。Windows 打包程式驗證前後台版面、存檔重開、勾選與復原、表單編輯、原生剪貼簿、拖曳排序及跨產線移動。
